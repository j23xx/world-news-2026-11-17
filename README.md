The world's news of Tuesday 17 November 2026 in one 1024×1024 picture: a front page of the day's most consequential stories across every region, each with an original flat illustration, a world map of where they happened and the date in the masthead. `main.ts` copies the pre-rendered `entry.png` to `/output`; `design/front.html` is the page and `design/render.mjs` renders it with headless Chrome.

Entry for the make.fun bounty [Sum up 17 November's world news in one image](https://make.fun/bounty/news-image-20261117).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Re-render the image (needs Google Chrome): `node design/render.mjs`
